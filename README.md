# Stay Desk · 회사 콘도 예약 조회

조건 입력 또는 자연어 문의로 콘도 객실을 찾는 한국어 React/Vite + Express 페이지입니다.

## Windows에서 실제 확인하기

[Windows 실행 패키지](https://github.com/GOUNHAM/GPT_CODEX/raw/refs/heads/codex/windows-download/StayDesk-Windows-x64.zip)를 다운로드하고 **모두 압축 풀기 → StayDesk 폴더 → START.cmd 더블클릭** 순서로 실행합니다. 아이디와 비밀번호를 입력하면 브라우저가 자동으로 열립니다. 첫 화면은 D멤버스 일반 조회/실시간 모드이며, 리조트와 날짜를 선택해 실제 조회할 수 있습니다.

Node.js 설치나 npm 명령어 입력은 필요하지 않습니다. 계정 정보는 패키지에 포함하지 않고 실행 중 메모리에서만 사용합니다. 서버는 127.0.0.1에만 바인딩합니다. 실행 창에서 Ctrl+C를 누르면 종료합니다. 회사 계약 재고·우대요금은 별도 권한이 필요합니다.

실행기의 입력 숨김, 포트 선택, 기본 설정과 배포용 최소 의존성만 사용한 실제 조회는 Linux에서 검증했습니다. Windows 런타임은 공식 배포본의 SHA-256과 Windows x64 실행 파일 형식을 검증했지만, Windows OS에서 START.cmd를 직접 실행한 검증은 하지 못했습니다.

패키지를 다시 만들려면 `npm run build` 후 `python3 scripts/build-windows-package.py`를 실행합니다. `releases/`는 Git에서 제외됩니다. 이 스크립트는 공식 Node.js 24 LTS Windows 런타임을 체크섬 검증한 후 Express/Playwright의 고정된 버전과 빌드된 앱만 복사합니다. .env, 쿠키, Git 메타데이터, 조사 파일은 제외하고 현재 계정 값이 번들에 포함되지 않았는지 검사합니다.

## 현재 동작하는 실제 연동

소노 공식 사이트에서 실제 로그인, 세션 검증, 일반 예약 객실 상태, 공식 면적·정원·취사 정보와 날짜별 요금 조회를 검증했습니다. 양양·삼척 및 월을 넘기는 숙박으로 검증했습니다. 재고는 시점에 따라 변하므로 검증 때의 객실 수를 현재 재고로 보장하지 않습니다.

조회 기준을 명시적으로 선택합니다.

- **회사 회원권**: 기본값입니다. 현재 계정의 회사/계약 예약용 회원권 목록은 0개입니다. 이 기준은 `SONO_MEMBERSHIP_MISSING`으로 차단하며 일반 요금으로 자동 대체하지 않습니다. 회사 계약 요금은 회사 예약 경로/권한이 별도로 확인되어야 합니다.
- **D멤버스 일반 조회**: 전체 회원번호 목록에서 확인한 D멤버스 1개를 사용합니다. 공식 예약 구분 API가 본인 예약 코드 `Y`를 반환하는지 다시 확인합니다. 실제 일반 예약 재고·요금을 반환하며 **회사 계약 재고·우대요금이 아닙니다.**
- **예시 데이터 모드**: 화면 체험용 가상 데이터입니다. 실시간 실패 시 예시 결과로 대체하지 않습니다.

이전 조사에서는 예약용 회원권 목록만 확인해 모든 실시간 조회가 불가능하다고 판단했습니다. 이후 전체 회원번호 목록에 D멤버스가 있음을 확인하여 일반 조회를 구현했습니다. 회사 회원권 0개라는 사실과 일반 조회 가능 여부를 분리해 표시합니다.

## 사용법

1. 필요하면 **연결 확인**을 눌러 계정 상태를 확인합니다.
2. **D멤버스 일반 조회**를 선택합니다. 회사 계약 정보가 필요한 경우 회사 회원권 기준을 유지합니다.
3. 지역과 **리조트 한 곳**을 선택하고 체크인·체크아웃, 성인·아동, 객실 유형·최소 면적을 입력합니다. 같은 장소의 호텔·리조트 객실을 함께 조회합니다.
4. **실시간 조회** 모드를 선택하고 **예약 가능한 객실 찾기**를 누릅니다.
5. 객실을 가격/면적순으로 정렬하고, 상세 보기에서 일자별 기본요금·회원등급 할인·숙박 합계를 확인하거나 결과를 복사합니다.

평수는 공식 안내의 ㎡를 환산한 값입니다. 분양 평형과 다를 수 있습니다. 추가 인원·옵션 비용은 별도일 수 있으며, 조회는 객실을 확보하거나 예약을 확정하지 않습니다.

## 결과를 확인하는 방식

- 공식 예약 목록에 나온 직영 리조트만 선택한 장소에 매핑합니다. 제휴/외부 사업장은 현재 제외합니다.
- 요청한 **모든 숙박일에 동일한 객실 유형 코드**의 재고가 있는지 확인합니다. 체크아웃일은 숙박일에서 제외합니다.
- `A`(예약원활), `E`(마감임박)만 예약 가능으로 취급합니다. 대기·추첨·매진·예약 불가 상태는 포함하지 않습니다.
- 상세 조회에서도 예약 가능 상태를 다시 확인합니다. 재고/응답 누락을 매진으로 처리하지 않습니다.
- 객실 코드에 연결된 공식 시설 안내에서 면적과 최대 인원을 확인합니다. 최대 인원이 없고 기준 인원만 표시되면 기준 인원으로 보수적으로 필터링합니다.
- 면적을 확인하지 못하면 임의 값을 넣지 않습니다. 면적 무관 조회에는 미확인으로 표시하고, 최소 면적 조건이 있으면 제외합니다. 필수 사양 확인 실패로 전부 제외되는 경우 정상 빈 결과로 처리하지 않습니다.
- 날짜별 금액 합계와 공식 총액을 대조합니다. 공식 응답의 별도 `levelAmt` 회원등급 할인으로 정확히 설명되는 차이는 기본요금·할인·실제 합계로 나눠 표시합니다. 확인되지 않은 차이를 임의로 보정하지 않습니다.
- 한 번에 최대 3개의 조회 작업을 진행합니다. 결과가 너무 많은 경우(80개 초과) 유형을 좁혀야 합니다. 일부만 조용히 반환하지 않습니다.

## 실행과 검증

Node.js 24에서 검증했습니다.

```sh
cd /workspace/GPT_CODEX
npm ci
npm run dev
```

기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. 프로덕션은 다음과 같습니다.

```sh
npm test
npm run build
npm start
```

- `npm test`: 외부 접속 없는 테스트 26개. 자연어/입력, 로그인/세션/잠금, 회사·일반 자격, 숙박 기간 전체 재고, 공식 사양과 할인 금액 검증.
- `npm run test:ui`: 서버 실행 후 데스크톱·모바일 검증. 계정 확인과 실시간 응답은 모의 처리해 실제 계정에 추가 로그인하지 않습니다. 예시 조회/검증 API는 실제 로컬 서버를 사용합니다.
- UI 테스트의 Chromium 기본 경로는 `/usr/bin/chromium`이며 `CHROMIUM_PATH`로 변경합니다.
- `artifacts/`에는 Git에서 제외되는 캡처/체험 파일이 있습니다. 체험 HTML은 실제 계정 조회를 하지 않습니다.

실제 계정 검증은 사용자가 요청한 통합 검증 중에만 수행합니다. 일반 테스트에서 외부 로그인을 반복하지 않습니다.

## 환경 변수와 보안

`.env.example`을 참고해 서버에만 설정합니다.

- `SONO_USERNAME`, `SONO_PASSWORD`: 소노 계정. 현재 클라우드 환경에 주입되어 있습니다.
- `PORT`: 서버 포트(기본 3000).
- `SONO_CONNECTOR_URL`, `SONO_CONNECTOR_TOKEN`: 선택적인 별도 검증 조회 서비스. 내장 일반 조회에는 필요하지 않습니다.

인증 정보, 쿠키, 회원번호와 프로필은 브라우저/로그/파일에 저장하거나 전달하지 않습니다. `.env`는 Git에서 제외됩니다. `VITE_` 변수에 인증 정보를 넣지 마세요. HTTPS 프록시와 CA 신뢰를 유지하고 TLS 검증을 끄지 않습니다. 계정 정보를 리다이렉트 대상에 전송하지 않습니다.

서버 메모리의 세션은 최대 15분, 자격 목록은 1분 유지합니다. 로그인 실패/잠금/추가 인증은 30분 재시도 제한이 적용됩니다. 자동으로 대표회원번호를 바꾸거나 회원권을 연결하지 않습니다. 동시 로그인은 하나로 합치고 동시 객실 조회는 추가 요청을 거절합니다.

**예약·가예약·대기 등록·결제·취소 API는 호출하지 않습니다.** 사용자가 고른 조건으로 읽기 전용 조회만 진행합니다. 회사용 배포에는 SSO/HTTPS를 별도로 적용해야 하며, 현재 앱 자체의 이용자 인증은 포함하지 않습니다.

## API와 파일

- `GET /api/status`: 원격 접속 없이 설정 여부와 최근 연결 상태.
- `POST /api/connection/check`: 실제 로그인 → 세션 → 예약용/전체 회원번호 목록 확인. 회사 회원권 개수와 일반 예약 가능 여부만 반환합니다.
- `POST /api/parse`: 자연어 문의를 입력 조건으로 해석.
- `POST /api/search`: 예시 또는 실시간 조회.

실시간 일반 조회 요청 예시:

```json
{
  "mode": "live",
  "criteria": {
    "bookingBasis": "standard",
    "region": "강원",
    "destination": "yangyang",
    "checkIn": "2027-01-20",
    "checkOut": "2027-01-22",
    "adults": 2,
    "children": 2,
    "roomType": "suite",
    "minSize": 0
  }
}
```

`bookingBasis` 생략 시 회사 기준입니다. `destination` 등은 `server/domain.js`의 목록을 따릅니다. 날짜/기간/인원은 서버에서도 검증합니다.

- `server/sono-client.js`: 공식 로그인, 세션, 자격 확인, 읽기 전용 API 제한.
- `server/sono-rooms.js`: 실제 일반 재고/사양/가격 조회와 결과 검증.
- `server/domain.js`: 조건 검증과 자연어 해석.
- `server/provider.js`: 예시 데이터 및 선택적 외부 조회 서비스.
- `src/main.jsx`, `src/style.css`: 입력·연결·목록·상세·복사 UI.
- `tests/`: 네트워크 없는 검증과 브라우저 검증.

자연어 해석은 외부 AI가 필요 없는 규칙 기반입니다. 날짜, 박수, 알려진 장소, 성인·아동, 평수와 유형을 지원합니다. 모호한 상대 일정은 정확한 날짜 확인을 요청합니다. 모든 한국어 표현·부정문·대안을 이해하지는 않으므로 적용한 조건은 폼에서 확인해야 합니다.

선택적 외부 서비스에는 조회 조건만 POST하고 소노 계정은 보내지 않습니다. 외부 응답은 `source: "sono"`, 5분 이내 `checkedAt`, `rooms`와 객실별 요청 날짜/예약 가능 상태/실제 숫자 사양·요금을 요구합니다. 외부 서비스 자체의 정보 정확성은 별도 검증이 필요합니다.
