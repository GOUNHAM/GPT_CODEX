# Stay Desk Windows 실제 조회 앱

[**Windows 실행 파일 ZIP 다운로드**](https://github.com/GOUNHAM/GPT_CODEX/raw/refs/heads/codex/windows-download/StayDesk-Windows-x64.zip)

1. ZIP 파일을 다운로드합니다. 비공개 저장소라면 이 저장소에 접근 가능한 GitHub 계정으로 로그인하세요.
2. 다운로드한 파일을 우클릭하고 **모두 압축 풀기**를 선택합니다.
3. 안의 **StayDesk** 폴더에서 **START.cmd**를 더블클릭합니다.
4. 실행 창에 소노 아이디와 비밀번호를 입력합니다. 비밀번호는 화면에 보이지 않으며 파일에 저장되지 않습니다.
5. 브라우저가 열리면 리조트와 날짜·인원을 선택하고 **예약 가능한 객실 찾기**를 누릅니다.

Windows 10/11 64비트용입니다. 별도 Node.js 설치나 npm 명령어 입력은 필요 없습니다.

- 실제 소노 D멤버스 일반 예약 조회입니다. 회사 계약 재고·우대요금과는 다릅니다.
- 예약 확정이나 결제를 하지 않습니다.
- 종료하려면 실행 창에서 Ctrl+C를 누르세요.
- ZIP에는 계정 정보·쿠키가 포함되지 않습니다.
- 패키지 서버·실제 조회·브라우저 동작과 공식 Windows 런타임 체크섬을 검증했습니다. Windows OS에서 START.cmd 자체를 실행하는 검증은 하지 못했습니다.
- ZIP 링크가 바로 다운로드되지 않으면 파일을 열고 오른쪽 위 **Download raw file**(아래쪽 화살표) 버튼을 누르세요.
