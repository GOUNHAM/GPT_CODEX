Stay Desk · Windows 실제 콘도 조회

[실행 방법]
1. ZIP 파일을 다운로드하고 마우스 오른쪽 버튼 → 모두 압축 풀기를 선택합니다.
2. 압축을 푼 StayDesk 폴더에서 START.cmd를 더블클릭합니다.
3. 열린 창에 소노 아이디와 비밀번호를 입력합니다.
   비밀번호는 입력해도 표시되지 않으며 파일에 저장되지 않습니다.
4. 기본 브라우저가 자동으로 열립니다.
5. 리조트와 체크인/체크아웃, 인원 등을 선택한 후
   '예약 가능한 객실 찾기'를 누릅니다.

별도의 Node.js 설치, npm 명령어 입력, GitHub 설정은 필요 없습니다.
Windows 10/11 64비트용입니다. 인터넷 연결이 필요합니다.
회사 PC의 프로그램 실행 제한이 있으면 회사 IT 담당자의 허용이 필요할 수 있습니다.

[조회 기준]
처음에는 'D멤버스 일반 조회' + '실시간 조회'로 시작합니다.
이는 실제 소노 일반 예약 재고/요금이며 회사 우대요금과 다릅니다.
회사 계약 조회를 선택하면 해당 계정의 회사 예약용 회원권이 필요합니다.
면적은 공식 ㎡를 평으로 환산하며 분양 평형과 다를 수 있습니다.
조회는 예약이나 결제를 진행하지 않습니다.

[보안 및 종료]
앱은 실행한 PC에서만 접속할 수 있으며 인터넷에 공개하지 않습니다.
배포 파일에는 소노 아이디/비밀번호/로그인 쿠키가 포함되지 않습니다.
조회 중에는 검은 실행 창을 열어 두세요. 종료하려면 그 창에서 Ctrl+C를 누르세요.
종료하면 메모리에 있던 로그인 세션은 폐기됩니다.

[확인 범위]
서버와 실제 소노 연동, 데스크톱/모바일 UI는 Linux 환경에서 검증했습니다.
이 ZIP에 포함된 Windows Node.js는 공식 배포본의 SHA-256을 검증했습니다.
이 작업 환경에는 Windows가 없어 Windows에서 START.cmd를 직접 실행해 검증하지는 못했습니다.

[외부 웹주소로 접속하려면]
이 패키지는 PC에서 실행하는 앱입니다. 공용 웹주소가 생성되지는 않습니다.
회사 서버나 별도 호스팅에 배포하려면 그 서버의 접속 정보와 사용자 인증 설정이 필요합니다.
